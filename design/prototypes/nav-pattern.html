Prototype state: Top row pattern in three role variants. Tab once to see the skip link.

Top row navigation

One top row for every signed-in role. Items depend on the roles the person holds. Every page reachable without an id is listed.

Anatomy

  1. Tenant mark and name. Goes to Home. Tenant logo is a self-hosted token.
  2. Role links. Pages the person may open without an id. The current page has aria-current="page", a bold weight and an underline bar.
  3. Role chip. Shows the active role in words, so people with several roles know which view they are in.
  4. Notifications. A number badge, plus hidden text "unread". The number is the cue, not the colour.
  5. Help. Opens help for the current page.
  6. Account. Avatar with initials as fallback. Goes to /app/me.

Behaviour notes

  • Real pages have exactly one <nav aria-label="Main navigation">. The examples above carry a suffix only because three appear on one page.
  • On narrow screens the row wraps. Links keep a 44 pixel target. No hidden menu needs a script.
  • The skip link is the first focusable element. It appears on focus and moves focus to main.
  • There is no keyboard trap. Tab order follows reading order.
