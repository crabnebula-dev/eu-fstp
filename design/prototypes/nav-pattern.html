Prototype state: Sidebar pattern in three role variants. Tab once to see the skip link.

Sidebar navigation

Signed-in pages share one layout: a full-width top bar, a left sidebar and the main content. Public pages use a simpler layout with links in the top bar and no sidebar.

Layouts

  • App layout. Every signed-in page. Top bar with tenant mark, notifications, help and avatar. Sidebar with navigation. Main content up to 960 pixels wide.
  • Public layout. Sign-up, sign-in, public calls and open data pages. Top bar with public links and language. No sidebar.

Pages supply only their main content. The layout comes from the role, so a router can map each layout to one layout route.

Sidebar anatomy

  1. Masquerade banner slot. Hidden by default. A yellow strip appears when a Tenant admin views the platform as another role.
  2. Role chip. Shows the active role in words, so people with several roles know which view they are in.
  3. Navigation label and links. One vertical list. The current page has aria-current="page", a bold weight, a left bar and a light blue background.
  4. Account and Sign out. At the bottom on desktop. Account goes to /app/me.

Top bar anatomy

  1. Tenant mark and name. Goes to Home. Tenant logo is a self-hosted token.
  2. Notifications. A number badge, plus hidden text "unread". The number is the cue, not the colour.
  3. Help. Opens help for the current page.
  4. Avatar. Shown on narrow screens only. On desktop the sidebar Account link replaces it.

Behaviour notes

  • Real pages have exactly one <nav aria-label="Main navigation">. The examples above carry a suffix only because three appear on one page.
  • From 900 pixels wide the sidebar is 220 pixels, sticky, and fills the height below the top bar.
  • Below 900 pixels the links show as a vertical list under the top bar. Links keep a 44 pixel target. No hidden menu needs a script.
  • The skip link is the first focusable element. It appears on focus and moves focus to main.
  • There is no keyboard trap. Tab order follows reading order: top bar, sidebar, then main.
